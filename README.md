# NumPy Statistical Analysis

## Task 15 – AI & ML Track

This project performs statistical analysis on a student marks dataset using NumPy.

## Objective

The objective of this task is to practice applying NumPy statistical functions to numerical data and identify important patterns in the dataset.

## Dataset

The dataset contains marks of 10 students:

[78, 85, 92, 67, 88, 74, 95, 81, 69, 90]

## Technologies Used

- Python
- NumPy
- Jupyter Notebook

## Statistical Calculations

The following statistical measures were calculated:

- Mean
- Median
- Standard Deviation
- Minimum
- Maximum

## Results

| Statistic | Value |
|-----------|-------|
| Mean | 81.9 |
| Median | 83.0 |
| Standard Deviation | 9.24 |
| Minimum | 67 |
| Maximum | 95 |

## Observations

1. The average marks are 81.9.
2. The median marks are 83.
3. The standard deviation is approximately 9.24, showing moderate variation.
4. The minimum mark is 67 and the maximum mark is 95.
5. The median is slightly higher than the mean because some lower marks pull the mean downward.

## Conclusion

NumPy makes it easy to perform statistical calculations on numerical datasets. The analysis shows that the students generally performed well, with most marks concentrated around the low 80s.
